# 架空データ

ここのデータはすべて架空です。実在の人・場所・番号・介護ソフトとは関係ありません。電話番号と郵便番号は実在しない「000」始まりです。

- 人物と村の設定（岡野ハルさん、𠮷川さん夫婦、ハッカ村）は、大会の開始前に用意した架空の設定をもとにしています。データのファイルは期間中に作りました
- `keahakka_*.csv`：架空の介護ソフト「けあはっか」が出すケアプランの CSV という想定。見出しと表記をわざと揃えていません。実在のソフトが同じ列を出せるとは限りません
- `keahakka.mapping.json`：読み解き役の答え合わせに使う正解
- `hakka-village.config.json`：ハッカ村の出力の形と物差し
- 作り直すときは `python scripts/make-samples.py`
