# hinan-hanashi（仮の名前）

個別避難計画づくりを支える道具。**同じことを二度聞かない。空いた時間で、もしもの話をする。**

Built with Claude: Japan 2026 の期間中（2026-11-02〜）に開発しています。

## 何をする道具か
ケアマネジャーなど、お宅を訪ねる人のための道具です。

1. 介護ソフトの CSV を読み、分かっていることは聞き直さない
2. 残った話を、暮らしの言葉のきっかけで1つずつ聞く。聞いたことをご本人に確かめながら、ボタンか F2 キーを長押ししている間だけ復唱し、短く押すと、その文字が計画に入っていく。入った欄には色が付き、違っていれば人が別の欄へ移せる。頼めたかどうかは人が印を付ける
3. 穴が見つかったら、物差しを示して割り込み、「雨の夜に、電話を1本」のような小さな頼みごとの案にする
4. 本人の1枚を渡す。本人が同意した項目だけ、渡す様式の CSV に出す（同意が1つでもあれば、本人を確かめる列〔氏名、住所など〕は一緒に出る。画面に列の名前を出す）。介護ソフトと同じ見出しの CSV にも、別の同意で書き出せる

渡す様式と入口の CSV の見出しを読み、聞く欄を合わせて作ります。計画に無い列は、話の中で聞く欄として足します。見本はハッカ村とミント市（どちらも架空）で、様式を増やせる作りです。介護ソフトへ実際に取り込めるかは、ソフトの対応しだいです。

国の調査（2026-04-01）を集計すると、計画がない約568万人のうち同意済みは約23万人（4%）で、約546万人は同意の手前にいます。内訳は分かりません。だから、書く手間を減らすだけでなく、話す時間を作ることをねらっています。

## 守っていること
- AI は高齢者に話しかけず、連絡もしません。決めるのは人です
- 医療の判断はしません
- デモのデータはすべて架空です。実在の個人情報は入れません
- 氏名・住所・電話番号・生年月日を Claude に送らないよう、ブラウザの中で記号や呼び名に置き換え、サーバーの入口でも形を調べます。送る中身は画面で見られます
- ただし、機械には限界があります。入力していない人の名前は、「さん」が付かないときや平仮名のときに見分けられません。声メモでは「隣の人」「娘さん」のように続き柄で話してください。手伝う人の同意がない間は人の話が入った文を市向けの出力から隠しますが、言葉の一覧には限りがあるので、出す内容を人が読んで確かめてください。声の入力はパソコンの Chrome と Edge を前提にしていて、スマホでは確かめていません。声はブラウザの音声認識（Google）で処理されます。端末の中で処理する形への切り替えは今後の課題です。実際の運用の前に、人による確認と市の決まりの確認が必要です

## Claude の使い方
役目を3つに分け、[指示と答えの形](src/server/prompts.js)を1つのファイルにまとめています。

| 役目 | すること | 答えをどう確かめるか |
|---|---|---|
| 読み解き役 | CSV の列が計画のどの欄かを判断する | 分からない列は「分からない」のまま人に聞く |
| 書き取り役 | 声メモを計画に書き込む | 根拠の文字がメモに無い書き込みは捨てる。人が直した欄は上書きしない |
| 点検役 | 物差しに当たる穴と、頼みごとの案を出す | 物差しに無い指摘と医療の判断は捨てる |

話のきっかけの順番、サービスの無い曜日、CSV の変換、「間に合うか」の足し算はプログラムがします。AI を待たせず、結果がぶれないようにするためです。

## 動かし方
Node.js 22 以上で動きます。

```bash
node server.mjs
```

`http://localhost:5177` を開きます。鍵が無いと、台本の言葉にだけ反応する**仮の答え**で動き、画面にもそう出ます。

本物の Claude につなぐときは、部品を入れて `.env` に鍵を書きます（`.env.example` を参照）。

```bash
npm ci
```

```bash
node --env-file=.env server.mjs
```

鍵があるのに Claude が失敗したときは、仮の答えに逃げず、失敗と画面に出します。

## 確かめ方
```bash
npm test
```

本物の Claude を呼ばずに、送る中身、答えの受け取り方、外に置くときの決まりを調べます。

架空の人物の台本を本物の Claude に通し、出るべき指摘と出てはいけない指摘、かかった費用を確かめるには、次のコマンドを使います（有料です）。

```bash
node --env-file=.env scripts/try-claude.mjs --go
```

## 外に置くとき
`HOST=0.0.0.0` と、12文字以上の `APP_PASSWORD` が必要です。無いと起動しません。`PUBLIC_DEMO=1` で架空のサンプルだけになります。公開デモのサーバーは、架空のサンプル以外の列を読みません。回数の上限は `LIMIT_PER_MINUTE`（既定40）、`LIMIT_PER_DAY`（既定500）、`LIMIT_PER_CLIENT_DAY`（接続元ごと、既定200）です。

## Claude Code での作り方
- [フック](.claude/settings.json)：書き換えるたびにテストを流す。鍵の読み出し、公開への切り替え、履歴の上書きを止める。有料の実行は人に聞く
- [レビュー役](.claude/agents/privacy-reviewer.md)：書いた会話を見ていない読み取り専用のサブエージェントが、送る中身と出力を調べる
- Git のフック：コミットの前に、鍵と架空でない個人情報が混ざっていないかを調べる
