# hinan-hanashi（仮の名前）

個別避難計画づくりを支える道具。**同じことを二度聞かない。空いた時間で、もしもの話をする。**

Built with Claude: Japan 2026 の期間中（2026-11-02〜）に開発しています。開発中のため、まだ動きません。

## 守っていること
- AI は高齢者に話しかけず、連絡もしません。決めるのは人です
- 医療の判断はしません
- デモのデータはすべて架空です。実在の個人情報は入れません

## 動かし方
Node.js 22 以上で動きます。追加の部品は要りません。

```bash
node server.mjs
```

`http://localhost:5177` を開きます。テストは `npm test` です。

外に置くときは `HOST=0.0.0.0` と、12文字以上の `APP_PASSWORD` が必要です。無いと起動しません。

今は Claude につないでいません。列の読み取りは、画面に「仮の答え」と出る仮の処理です。
